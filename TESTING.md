# Проверка Split 4.0 — история и резервное копирование

Проверки запускаются из корня репозитория. Node.js 24, Python 3 и headless Chromium; тестовые зависимости установлены вне репозитория по README. Приложение не требует сборки.

```sh
export PLAYWRIGHT_MODULE=/tmp/split-test-tools/node_modules/playwright-core
export AXE_MODULE=/tmp/split-test-tools/node_modules/axe-core
export CHROMIUM_PATH=/usr/bin/chromium
node --test --test-isolation=none tests/core.test.cjs tests/history.test.cjs
python3 -m http.server 8000 --bind 127.0.0.1
# В другом терминале с теми же переменными:
node tests/browser.cjs
node tests/history-browser.cjs
node tests/accessibility.cjs
node tests/pwa-update.cjs
```

`SPLIT_URL` задаёт другой адрес сервера. PWA-тест поднимает свой временный сервер, меняет версии в памяти и не изменяет приложение. Для axe используется отдельный контекст `bypassCSP`; функциональные сценарии выполняются с действующей CSP.

Результаты текущего запуска: **26/26 модульных тестов** (9 расчётов + 17 истории), **12/12 сценариев калькулятора**, **9/9 групп сценариев истории**, **3/3 группы PWA**, **5/5 axe-сканирований калькулятора** и **4/4 axe-сканирования истории/импорта** без нарушений выбранных правил. `node --check` и `git diff --check` также прошли.

Покрытие:

- `core.test.cjs`: прежние 9 денежных тестов, включая 1000 детерминированных наборов. Файл `core.js` не изменялся.
- `history.test.cjs`: миграция v2 и старых отдельных ключей, добавление к существующей истории, сохранение исходных байтов/черновиков/балансов; CRUD и перезагрузка; экспорт одного/всех/нулевого числа расчётов; предпросмотр без записи, объединение, повторные и конфликтующие импорты, старый JSON; неверные суммы/ID/даты/версии и XSS; квота, повтор миграции, конфликт вкладок, восстановление повреждённого хранилища с обязательным архивированием оригинала.
- `browser.cjs`: прежние 12 сценариев калькулятора адаптированы к входу через список истории. Проверяются суммы, компенсации, сохранение, неверные черновики, тема, ширины, офлайн, буфер, сброс, миграция и ошибки хранения.
- `history-browser.cjs`: создание, редактирование, переименование и перезагрузка; реальные скачиваемые JSON; уникальный ID копии; отмена/подтверждение удаления и импорта; неверный файл; повторы/конфликты; XSS в карточке и предпросмотре; восстановление повреждённого оригинала; адаптивность обеих тем и axe главного экрана/импорта.
- `pwa-update.cjs`: 3 группы — неудачное обновление сохраняет прежнюю оболочку; принятое обновление сохраняет расчёт и посторонние кэши; офлайн в подпапке, неизвестный JS не получает HTML.
- `accessibility.cjs`: прежние 5 axe-сканирований калькулятора: 390/1280, обе темы и диалог сброса. Скриншоты пишутся в `/tmp/split-dark.png` и `/tmp/split-light.png`.

Ни один автоматический тест не заменяет ручную проверку на физических iPhone/Safari и Android/Chrome. Перед выпуском проверить установку PWA, cold start в авиарежиме, обновление 3.0 → 4.0 на HTTPS с реальными данными, файловые диалоги и скачивание JSON, системный буфер, safe area/клавиатуру/поворот, VoiceOver/TalkBack, масштаб 200%, приватный режим и ограниченную квоту. Автоматическое axe-сканирование не является сертификацией WCAG.

Ограничения хранения и стратегия безопасного восстановления описаны в README. Приложение не синхронизирует данные между устройствами и не гарантирует транзакционность строго одновременных записей localStorage. Публикация приложения и merge в main не входят в эту задачу.
