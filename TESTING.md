# Проверка восстановленного Split 3.0

Реализация восстановлена по истории чата поверх актуальной `main` (`95b9f55`). Приведённые ниже проверки заново выполнены в текущей среде, это не перенос результатов прежней сессии.

## Автоматические проверки

Среда: Linux, Node.js 24, headless Chromium, Playwright Core. Приложение раздавалось Python HTTP-сервером.

| Команда | Результат |
| --- | --- |
| `node --test --test-isolation=none tests/core.test.cjs` | 9 тестов пройдено, включая 1000 детерминированных наборов |
| `node tests/browser.cjs` | 12 сценариев пройдено; необработанных ошибок JS нет |
| `node tests/pwa-update.cjs` | 3 группы проверок пройдены |
| `node tests/accessibility.cjs` | 5 сканирований axe-core 4.11; нарушений выбранных правил WCAG A/AA не обнаружено |
| `node --check` для core.js/script.js/pwa.js/sw.js | Синтаксис корректен |
| `git diff --check` | Ошибок пробельных символов нет |

Тесты денежных расчётов проверяют округление десятичных строк, копейки, компенсации и переплату компенсацией, нулевую цель, кассу, лимиты и неверные индексы. На 1000 наборах проверено, что сумма долей равна цели и предложенные операции полностью погашают балансы.

Браузерные сценарии: расчёт; сохранение без blur и смена темы; ошибочный черновик после перезагрузки; компенсация и смена направления; XSS-имя; ширины 320/375/390/412/768/1280, подписи и шрифты полей, диалог; офлайн-перезагрузка и ресурсы; добавление/удаление, буфер, очистка результата и сброс; конфликт вкладок; миграция с индексом получателя 0; повреждённый JSON; исчерпание квоты.

PWA: неудачная загрузка нового кэша оставляет старую версию; принятое обновление сохраняет ввод, удаляет старый кэш Split и сохраняет посторонний; офлайн из подпапки работает, неизвестный JS не получает HTML вместо скрипта.

Доступность: ширины 390/1280, обе темы и открытый диалог. Сканирование дожидается завершения анимаций. Выбранные правила: wcag2a, wcag2aa, wcag21aa, wcag22aa. Автоматическая проверка не означает сертификацию всего WCAG.

## Ручные проверки — не выполнены

Перед выпуском проверить физические iPhone/Safari и Android/Chrome:

1. Экранную клавиатуру с запятой/точкой, отсутствие автозума, видимость поля и кнопок, закрытие клавиатуры, поворот и safe area.
2. Управление одной рукой, увеличение текста и масштаб 200%, порядок фокуса, VoiceOver/TalkBack и озвучивание ошибок.
3. Установку PWA, завершение первой загрузки, холодный запуск после закрытия в авиарежиме.
4. Обновление на тестовом HTTPS-размещении с заполненной формой, а также прерывание загрузки новой версии.
5. Системный буфер, скачивание JSON, сброс/отмену, приватный режим и запрещённое хранилище.

Скриншоты обеих тем автоматически создаются тестом доступности в `/tmp/split-dark.png` и `/tmp/split-light.png`; они не заменяют ручные проверки на устройствах.

## Ограничения

- На телефонах для PWA нужен HTTPS, офлайн появляется после успешной установки service worker.
- Кэш версионируется вручную в sw.js.
- Браузер может очистить localStorage; JSON-экспорт есть, импорта нет.
- Обнаружение конфликтов вкладок не гарантирует сериализацию строго одновременных записей.
- Жадный план корректен, но не обязательно минимален по числу переводов.
- Merge в main и публикация GitHub Pages не выполнялись.
