# Split 3.0: мобильный интерфейс, точные взаиморасчёты и офлайн-PWA

Исправлен учёт выполненных компенсаций: перевод уменьшает долг отправителя и сумму к получению адресата. Денежный модуль считает в копейках, распределяет остаток и отдельно отображает операции с общей кассой.

Добавлены мобильный Dark Glass с двумя темами, крупные элементы управления, нижняя навигация и safe area; немедленное сохранение с миграцией и обработкой ошибок; локальные ресурсы PWA, иконки, офлайн-кэш и обновление по действию пользователя; CSP и безопасный вывод имён. Приложение остаётся на HTML/CSS/JavaScript без runtime-зависимостей.

В текущей среде повторно прошли: 9 тестов расчётов (1000 наборов), 12 браузерных сценариев, 3 группы проверок PWA и 5 сканирований axe без обнаруженных нарушений выбранных правил. Подробности — TESTING.md. Ручные испытания на физических iPhone/Android, Safari, VoiceOver/TalkBack и установка PWA ещё нужны.

README содержит запуск, модель расчёта, команды тестов и порядок обновления кэша. localStorage не гарантирует транзакционность одновременных записей вкладок; JSON-экспорт пока без UI импорта. Merge и публикация не входят в этот PR.
